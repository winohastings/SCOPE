# C视角集中：奖励与优化机制诊断

本分析不进行训练；实际空间结果见C_REPORT。几何反事实、固定Critic GAE分解和输出bias梯度用于定位，不等同重新训练因果实验。

## 1. 奖励计算与接入

相同ROI同相机四次bonus=0.01，四相机各一次bonus=0.04；扣除原Focus成本后分别为-0.03和0。奖励确实偏好新增区域，没有把不同相机相同坐标错误地视为重叠。实际512条轨迹的奖励/GAE/normalized advantage重算见C_REWARD_AUDIT。

## 2. 奖励比重与样本区分度

- C：实际beta=0.01；按beta=.01计几何bonus=7.153472，原reward绝对值总和=61.330285，progress绝对值总和=25.215810，terminal绝对值总和=36.000000；首次Focus占bonus=49.486%；后续Focus新颖性≥.95比例=40.494%；bonus与Focus次数相关=0.9640143852858576。
- C0：实际beta=0.0；按beta=.01计几何bonus=7.527710，原reward绝对值总和=59.677100，progress绝对值总和=26.376843，terminal绝对值总和=34.000000；首次Focus占bonus=48.620%；后续Focus新颖性≥.95比例=44.199%；bonus与Focus次数相关=0.9636837689652815。
首次Focus无论选哪台相机都是全新区域，不能提供首相机偏好的相对信号。空间奖励不直接奖励相机多样性，同相机不重叠ROI同样可以得满分；不能将它等同于‘必须换相机’奖励。
beta=.01只让完全新增ROI的直接感知净成本为0，不提供额外正净感知收益；仍有导航step成本。单次最大0.01对比成功终止2.0，奖励累计和GAE才决定更新，不能仅凭这个比例就认定beta必然太小。

C的6次更新中，5次在camera输出bias投影上bonus与原奖励梯度相反；bonus梯度norm仅为原奖励的2.23%–22.95%。这支持局部竞争且探索信号较弱，但不是全部参数的因果归因。
其中4/6次bonus自身的camera-1 loss bias梯度为负，按简单梯度下降反而会抬高既有主视角bias。说明‘奖励了新增覆盖’不保证每批聚合梯度都降低重复主视角；共享序列信用、后续回报和样本相关性可以改变方向。
KL早停次数=0；没有证据称优化器被KL门禁完全阻断。
相机bias的四维梯度见JSON，正loss梯度在简单梯度下降下会降低该相机bias；此处不是Adam真实参数位移，不能忽略共享trunk、熵和后续minibatch。C0的bonus梯度仅为反事实，不曾用于其训练。
所有Focus仍共享导航级advantage：某一步的新覆盖奖励会连带给同一序列的首相机和重复动作信用；归一化后部分有正bonus的序列仍可得到负中心化贡献。这是保留原算法的信用分配限制，不是奖励未计算。
若两个梯度cosine为负，可说在该输出bias投影上存在竞争；不能据此认定全部Actor梯度或整个训练都受抑制。clip/KL日志用于排查更新限制，不把非零clipping自动视作故障。

## 4. 确定性解码与未识别因素

训练相机采样具有多视角并不保证argmax换相机；固定probe概率/熵/位置KL与真实确定性N4覆盖必须同时看。输出仍偏同相机，也可能是短预算尚未学到历史覆盖条件化，不能凭输入中存在coverage就认定已使用。
本实验只测试beta=.01、512步、单seed，未做beta消融、冻结导航reward消融或逐Focus信用分配对照，不能唯一归因‘比重太小’、‘导航回报抑制’或‘Actor无法利用coverage’。如需后续验证，应单独冻结一个因素，不直接上JS/KL或叠加多项奖励。
