# GPU 预算试点

## 设备与计量口径

两张RTX4090：GPU0一份冻结Qwen3.5/DiT-B加Actor/Critic，GPU1真实Habitat。没有复制
两份大模型，没有占用或结束无关用户进程。当前历史仍可能重编码，短历史pilot不等价
完整训练稳态。每个训练chunk执行最多八waypoint。

计时均来自真实环境/模型/优化器；不以token比或合成单元测试吞吐估算闭环。
“episode inclusive”包括reset/导航/反馈/更新/本次文件写入，“phase inclusive”还包括
新启动Habitat worker、依赖加载、scene初始化、进程收尾。两者不能互称同一个延迟。

## 完整训练成本外推（非授权）

仅沿用Stage1设计的199680导航transition/seed、3个seed作为参考规模。按本轮C实测：

- 忽略反复worker冷启动、采用episode-inclusive速率：约90.89墙钟小时/seed。
- 含当前极短phase启动摊销：约154.41墙钟小时/seed。
- 三seed、两卡预约口径约545.32–926.49 GPU小时。

这个区间不是可信置信区间，也不是完整训练预算上限；它只对应两种计时口径的线性
外推。未计长历史导致的推理增长、更多PPO epoch、更大minibatch/rollout的调度变化、
多环境排队、多seed方差、每次开发评估、失败重试及长episode开销。真实完整训练
成本可能更高，不能用当前小规模实测承诺训练完成时间。

没有启动完整训练，后续应先独立制定长历史稳态预算和研究批准门禁。
